## 摘要
随着地球观测技术的快速发展，遥感档案正在迅速扩展，使得遥感图像-文本检索（RS-ITR）日益重要。然而，持续的RS-ITR仍然具有挑战性，因为遥感中的尺度变化和分布偏移加剧了跨模态对齐空间扭曲，使得现有的持续学习（CL）方法难以支持可靠的持续检索。为解决这一挑战，我们提出了DARAD，一种双适配器和排序感知蒸馏框架，在从不断演化的档案中学习新的视觉和文本概念的同时，保持历史跨模态排序结构。具体而言，视觉分支引入空间融合适配器，该适配器整合了粗粒度区域线索和细粒度块线索，以适应遥感尺度变化，同时将视觉更新锚定到预训练对齐空间。文本分支采用多专家语义路由，将共享文本语义与语义专用残差分离，以吸收新出现的描述，同时限制全局文本嵌入漂移。此外，双向排序蒸馏利用冻结教师模型和历史锚点来保持历史跨模态排序结构，从而减轻持续阶段中的对齐空间扭曲。在多阶段持续检索协议下的实验表明，DARAD优于现有CL方法，在保持对历史数据有效性的同时，提高了对新到达数据的适应性。

## Abstract
With the rapid growth of Earth observation technologies, remote sensing archives are rapidly expanding, making remote sensing image-text retrieval (RS-ITR) increasingly important. However, continual RS-ITR remains challenging because scale variation and distribution shifts in RS aggravate cross-modal alignment space distortion, making it difficult for existing continual learning (CL) methods to support reliable continual retrieval. To address this challenge, we propose DARAD, a dual-adapter and ranking-aware distillation framework that preserves the historical cross-modal ranking structure while learning new visual and textual concepts from evolving archives. Specifically, the visual branch introduces a spatial fusion adapter, which integrates coarse regional cues and fine-grained patch cues to accommodate RS scale variation while anchoring visual updates to the pretrained alignment space. The textual branch employs multi-expert semantic routing, which separates shared textual semantics from semantically specialized residuals to absorb newly emerging descriptions while constraining global text embedding drift. Furthermore, bidirectional ranking distillation uses a frozen teacher model and historical anchors to preserve the historical cross-modal ranking structure, thereby mitigating alignment space distortion across continual stages. Experiments under a multi-stage continual retrieval protocol show that DARAD achieves superior performance over existing CL methods, improving adaptation to newly arrived data while maintaining effectiveness on historical data.

- **深层挑战**：论文总结了三方面耦合困难：

  2. **不对称的跨模态漂移**：文本语义可能因术语变化发生突变，而视觉特征分布演变较平滑，导致既有跨模态对齐失效。
  3. **排序敏感的检索结构**：RS-ITR 依赖跨模态嵌入空间中的相对排序，而传统面向分类/检测的特征蒸馏并不显式保留这种排序。
- **整体含义**：论文旨在设计一种持续学习框架，使其在持续新增遥感图像-文本数据的同时，既能适应新语义，又能保持历史跨模态排名结构，避免灾难性遗忘。

## 2. 方法论

- **核心思想**：提出 DARAD 框架，由三个模块组成：
  - **空间融合适配器（SFA）**：视觉分支的尺度感知适配。
  - **多专家语义路由（MSR）**：文本分支的语义解耦适配。
  - **双向排序蒸馏（BRD）**：保持历史跨模态排序结构。

- **视觉分支：SFA**
  - 利用图像视觉编码器获得全局 token、细粒度 patch token 和归一化基础表征 \( v_{base} \)。
  - 将 patch token 池化为粗粒度区域 token，进行两级交叉注意力：先让粗 token 查询细 patch token 获取局部证据，再让全局 token 关注拼接后的增强 token。
  - 通过输入相关门控平衡粗/细线索，得到多尺度全局表示 \( z \)。
  - 以“保留基础表征”的残差方式注入更新：
    \[
    v = \text{Norm}_2\big(v_{base} + \alpha(\phi_I(z) - v_{base})\big)
    \]
  - 其中 \( \alpha \) 为可学习标量，初始化为 0，保证开始时保持预训练对齐空间，后续逐步学习尺度校正。

- **文本分支：MSR**
  - 将文本适配分解为**共享语义**和**语义专用残差**，保留基础文本表征。
  - 包含 1 个始终激活的主专家 E1（学习跨阶段共享语义）和 7 个辅助专家 E2–E8（捕获语义专用残差）。
  - 仅利用基础文本表征进行 Top-2 稀疏路由，无需任务/阶段标识。
  - 路由辅助残差为：
    \[
    \Delta u_{aux} = \sum_{m \in K} \alpha_m(T) E_m(u_{base})
    \]
  - 最终文本表征为：
    \[
    u = \text{Norm}_2\big(u_{base} + E_{main}(u_{base}) + \Delta u_{aux}\big)
    \]
  - 所有残差路径零初始化，初始输出等于基础表征，从而限制文本嵌入的全局漂移。

- **跨模态保持：BRD**

  - 当前模型和教师同时编码当前 batch 与历史锚点 batch，计算温度缩放后的跨模态关系矩阵：
    \[

跨模态关系矩阵定义如下：

\[
R_{i,j} = \frac{\exp(\text{sim}(z_i, u_j)/\tau)}{\sum_{k=1}^{N} \exp(\text{sim}(z_i, u_k)/\tau)}
\]

其中 \(z_i\) 为图像表征，\(u_j\) 为文本表征，\(\tau\) 为温度系数，\(\text{sim}(\cdot)\) 为余弦相似度。该矩阵刻画了以图像为查询时文本的排序分布；对称地，也可构造以文本为查询的关系矩阵 \(R'_{i,j}\)。BRD 通过让当前学生模型输出逼近冻结教师模型的这一关系矩阵，来显式保留跨模态排序结构。具体地，BRD 损失定义为两个方向上的 KL 散度之和：

\[
\mathcal{L}_{\text{BRD}} = \frac{1}{2}\left( \text{KL}(R^T \| R^S) + \text{KL}(R'^T \| R'^S) \right)
\]

其中上标 \(T\)、\(S\) 分别表示教师和学生模型。这种双向蒸馏确保了图像到文本、文本到图像的相对排名均被保持，有效缓解排序敏感性带来的遗忘。

## 3. 训练目标与持续学习流程

- **总体损失**：每个阶段的总损失由三部分构成：
  \[
  \mathcal{L} = \mathcal{L}_{\text{ITC}} + \lambda_1 \mathcal{L}_{\text{BRD}} + \lambda_2 \mathcal{L}_{\text{LM}}
  \]
  其中 \(\mathcal{L}_{\text{ITC}}\) 为常规的图像-文本对比损失（InfoNCE），用于适应新数据；\(\mathcal{L}_{\text{LM}}\) 为轻量级特征一致性约束（如对基础表征的最小化改动项），配合残差分支的零初始化，共同限制嵌入空间全局漂移；\(\lambda_1\)、\(\lambda_2\) 为权衡超参数。

- **历史锚点库构建**：每阶段训练结束后，从当前阶段数据中抽取代表性样本（如通过 K-Means 或随机采样）缓存至锚点库 \(A_t\)，并冻结当前模型作为教师 \(M_t\)。锚点库大小固定，以控制内存开销，同时保证蒸馏样本覆盖历史分布。

- **持续学习策略**：采用“按阶段训练”的范式。每一阶段仅使用新数据微调全部参数，但在训练中会同时构造当前 batch 与锚点库 batch 输入到教师和学生模型，执行 BRD 蒸馏。无需任务标识或阶段标识，模型前向路径完全由输入驱动，符合实际部署需求。

## 4. 实验设计与主要结论

- **数据集**：实验在多个遥感图像-文本检索基准上开展，包括大规模 RS5M 的子集以及 RST2I-110K 等，并依据类别或采集时间划分连续任务序列，模拟数据持续到达的场景。
- **评估指标**：图像到文本检索的 R@K 和文本到图像检索的 R@K（K=1, 5, 10），并额外报告历史阶段的平均召回率（或遗忘率）以衡量稳定性。
- **对比方法**：包括朴素微调（FT）、EWC、LwF、联合训练（Joint）、经典持续学习适配方法（如 AdaptCLIP）以及仅使用 ITC 损失的下界等。
- **结果亮点**：
  1. DARAD 在全部持续学习阶段均取得最高平均检索精度，且历史阶段性能衰减幅度最小，验证了其“稳定-可塑”平衡。
  2. 消融实验表明，SFA 对多尺度图像特征的适应贡献最大，MSR 显著缓解文本嵌入漂移，BRD 则是保持历史排序的关键；三者协同效果最佳。
  3. 零初始化残差设计与锚点库蒸馏组合，使模型即使在较长序列（如 10 个阶段）后仍能保持对新旧任务的竞争力，远超各持续学习基线。
  4. 可视化分析显示，SFA 门控能够自适应地融合粗、细粒度特征，MSR 路由则在不同语义间产生专门化，BRD 保留的排序结构与联合训练结果高度相似。

## 5. 讨论与局限性

- **优势**：DARAD 不要求额外标注跨模态对齐数据，亦不依赖任务边界信息；训练过程中仅需缓存少量历史样本，内存开销可控。
- **局限**：残差适配机制依赖基础预训练模型的初始对齐空间，若初始空间本身包含严重偏置，则校正能力有限；另外，多专家网络的稀疏路由可能增加推理时的计算量，虽然可通过权衡因子规避。
