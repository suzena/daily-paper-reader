## 摘要
本文提出了一种仅基于观测的自主框架，用于无人水下航行器（UUV）在动态水下环境中的导航，该框架集成了持久占用地图构建、全局间隙感知规划与风险感知局部控制。所提出的流水线仅从机载声纳和深度图像观测构建占用地图，适配间隙约束的全局规划器（GP）以提供长 Horizon 结构，并集成强化学习（RL）策略以处理短距离跟踪与反应式避障。为进一步支持部分可观测下的决策，系统从机载传感器数据中学习紧凑的潜在状态表示，编码环境结构、障碍物动态与不确定性。引入具有分阶段监督的行为树（BT）蒸馏以提高安全性和训练稳定性，同时一种不确定性校准的蒸馏机制利用在线潜在模型不确定性对教师指导进行重新加权，在学习过程中强调不确定区域，时间到达碰撞（TTC）和间隙线索在规划与局部策略特征中保持显式。为证明框架的有效性，在基于 NVIDIA Isaac Sim 的高保真 GPU 加速仿真中建立了可复现的多种子评估协议，并将性能与仅 BT 和标准 RL 基线进行基准对比。所得结果表明在动态条件下鲁棒性和安全性得到提升，从而为部分可观测下的鲁棒 UUV 自主性提供了一种具有统一混合规划-学习架构的通用流水线和可复现方法论。

## Abstract
This paper presents an observation-only autonomy framework for Unmanned Underwater Vehicles (UUVs) navigation in dynamic underwater environments that integrates persistent occupancy mapping, global clearance-aware planning, and risk-aware local control. The proposed pipeline constructs occupancy maps solely from onboard sonar and depth image observations, adapts a clearance-constrained global planner (GP) to provide long-horizon structure, and integrates a reinforcement learning (RL) policy to handle short-range tracking and reactive avoidance. To further support decision-making under partial observability, the system learns a compact latent state representation from onboard sensor data, encoding environmental structure, obstacle dynamics, and uncertainty. Behavior tree (BT) distillation with staged supervision is introduced to improve safety and training stability, while an uncertainty-calibrated distillation mechanism reweights teacher guidance using online latent-model uncertainty, emphasizing uncertain regimes during learning, with time-to-collision (TTC) and clearance cues remaining explicit in planning and local policy features. To demonstrate the efficacy of the framework, a reproducible multi-seed evaluation protocol is established in high-fidelity GPU-accelerated simulation using NVIDIA Isaac Sim, and performance is benchmarked against BT-only and standard RL baselines. The results obtained demonstrate improved robustness and safety under dynamic conditions, thus providing a general pipeline with a unified hybrid planning learning architecture and a reproducible methodology for robust UUV autonomy under partial observability.

## 1. 核心问题与研究动机

- **问题背景**：UUV（无人水下航行器）在动态水下环境中导航面临多重挑战：GPS拒止、声纳感知受限、水动力效应复杂、海洋生物与其它航行器等动态障碍物频繁出现。这些因素导致决策问题本质上是**部分可观测**且充满不确定性的。
- **现有方法不足**：
  - 传统规划方法（A*、RRT、Voronoi等）在静态已知环境中表现良好，但在**动态变化、感知不确定和时间变化场景下脆弱**；预计算路径容易失效，频繁重规划在噪声地图下会引入不稳定或过重计算负担。
  - 纯深度强化学习（DRL）方法（PPO、SAC等）**样本效率低**、训练初期存在**不安全探索**，且许多方法假设**特权状态访问**或简化障碍物模型，与真实部署的观测条件不符。
  - 已有系统常将建图、规划与控制**割裂评估**，掩盖了感知不确定性传播到规划决策时的界面级失效模式。
- **核心研究问题**：如何在**严格仅观测（observation-only）**约束下，构建统一、闭环、鲁棒的UUV导航全栈（建图→规划→控制），在动态环境中保持安全与高效？

## 2. 方法论

### 2.1 总体架构与核心思想

提出一个**混合规划–学习分层架构**（图1、图2），将古典规划的全局结构与学习策略的局部适应性相结合：

- **全局层**：间隙感知（clearance-aware）的Voronoi全局规划器提供长时域结构，RRT作为连通失败时的回退。
- **局部层**：RL策略（PPO）负责短距离跟踪与反应式避障。
- **中间表征**：潜在世界模型（Latent World Model）在部分可观测下提供紧凑状态表征，编码环境结构、障碍物动力学与不确定性。
- **训练机制**：行为树（BT）蒸馏 + 分阶段监督 + 不确定性校准的教师指导重加权。

### 2.2 声纳建图与风险表征

- 维护**静态层** \(M^s_t\) 和**动态层** \(M^d_t\) 两个独立占用网格层：
  - 静态层通过声纳命中/自由空间/深度一致性证据更新；
  - 动态层通过时间声纳不一致性与Doppler相对运动推断。
  - 末端采用 \(M_t(c) = \max(M^s_t(c), M^d_t(c))\) 融合。
- **严格仅观测约束**：仿真器侧动态标注仅作为调试辅助选项，所有报告实验保持禁用。
- 在线间隙场 \(\delta_t(c)\) 用于规划路径的间隙约束；风险标量图 \(R_t(c)\) 加权融合静态占用、动态占用与间隙惩罚。

### 2.3 分层全局与局部规划控制

- 全局规划在可穿越单元 \(\Omega_t = \{c \mid M_t(c) < \tau_{occ}, \delta_t(c) \geq d_{min}\}\) 上求解最小化代价 \(\sum_i \frac{\|p_{i+1}-p_i\|_2}{\max(\delta_t(p_i), \varepsilon_r)}\) 的路径。
- **事件触发重规划**（三类事件）：(i) 无进展/卡死检测；(ii) 安全/TTC事件（近障碍范围 + TTC阈值）；(iii) 地图或动态障碍物与前瞻路径相交（2.5s常数速度预测）。
- 局部策略输入特征 \(\phi_t = [\Delta p^{lh}_t, e^{\psi}_t, e^{ct}_t, v^b_t, \omega^b_t, \xi^{sonar}_t, \xi^{wm}_t]\)，其中 \(\xi^{wm}_t\) 为世界模型的单步预测残差与不确定性代理。
- **奖励塑形**（公式14）包含：生存奖励、路径进展、路径距离、横向误差、间隙违反、TTC惩罚、超速惩罚、姿态奖励、航向对齐奖励、终端成功/失败项等。
- **硬安全约束**在线执行：\(d^t_{min} \geq d_{coll}\)，\(\text{TTC}_t \geq \tau_{coll}\)，违反即终止。

### 2.4 BT蒸馏与不确定性校准

- 训练目标：\(L(\theta) = L_{RL}(\theta) + \lambda_t \mathbb{E}[\|\mu_\theta(\phi_t) - a^{BT}_t\|_2^2]\)，即RL目标 + 教师动作的MSE蒸馏。
- **分阶段调度**（公式17）：前800次迭代 \(\lambda=1.0\)（纯教师引导），800–1600次线性衰减至0.2，之后为0（纯RL优化）。
- **不确定性校准**：\(s_t = \text{clip}(1 + \alpha\bar{\sigma}_t, 1, s_{max})\) 缩放蒸馏权重，使**高不确定性轨迹获得更强的教师指导**。

### 2.5 潜在世界模型

- 结构：编码器 \(z_t = f_\phi(o_t)\) → 潜在动力学 \( \hat{z}_{t+1} = g_\psi(z_t, a_t)\) → 解码器 \(\hat{o}_{t+1} = h_\omega(\hat{z}_{t+1})\)。
- 损失：\(L_{WM} = L_{recon}(\hat{o}_{t+1}, \tilde{o}_{t+1}) + \beta\|z_{t+1} - \hat{z}_{t+1}\|_2^2\)，即重建损失 + 潜在动力学一致损失。
- 解码器输出高斯方差 \(\sigma_t\) 经EMA平滑得到不确定性代理，用于策略特征增强和蒸馏缩放（见2.4）。

## 6. 主要结论与发现

1. **课程蒸馏显著提升性能**：PPO curr. distill相比PPO w/o distill，成功率从0.20提升至**0.87（4.3倍）**，碰撞率从0.40降至0.15，TTS从114.2s降至**15.8s（7.2倍）**。
2. **样本效率明显改善**：蒸馏策略收敛更快、训练奖励更稳定（图4）。世界模型的重建与动力学损失平滑收敛，验证了紧凑潜在表征和稳定单步预测的有效性。
3. **鲁棒性良好**：低-中动态复杂度下（S≤8, D≤9, v≤1.5m/s），平均成功率82.8%、平均碰撞率1.1%，40个条件中38个零碰撞。主要退化出现在极端拥挤与超快障碍物场景，定义了操作边界而非一般性失效。
4. **安全性需权衡**：更大的间隙/TTC裕度可获得零碰撞，但代价是保守绕行、卡死和超时，反映安全-效率的权衡结构。
5. **轨迹质量提升**：蒸馏策略产生更平滑、目标导向更强的轨迹，减少振荡与不必要的偏离（图6）。

## 7. 方法优点

- **统一全栈架构**：建图→规划→控制闭环耦合（公式4中的递归G算子），而非孤立模块评估，端到端强制仅观测约束。
- **混合范式互补**：古典规划的全局结构（Voronoi最大化间隙）与RL的局部适应性结合，且不依赖特权地图信息。
- **不确定性显式建模**：潜在世界模型的解码器方差作为不确定性代理，同时用于策略特征增强和蒸馏权重调节（ \(\lambda^{risk}_t = \lambda_t s_t\) ），使学习在不确定区域获得更多教师引导。
- **安全性机制多元**：奖励塑形 + 硬安全约束（碰撞/TTC立即终止）+ BT教师引导 + 渐进式蒸馏退火，多层防护。
- **实验方法严谨**：多种子协议、可复现参数表、事件触发重规划设计（卡死/TTC/路径相交）、严格排除动态标注辅助。
- **具身细节考虑**：超速惩罚、姿态（倾角）惩罚、控制能耗惩罚等，贴近真实部署需求。

## 8. 不足与局限

- **仿真与真实差距**：作者明确声明这是仿真证据而非真实可用性声明。最脆弱的迁移部件包括声纳伪影、水动力失配与洋流、定位漂移、感知噪声、作动器延迟/饱和。
- **极端条件退化**：当障碍物速度达3.0m/s而机器人最大0.6m/s时，反应裕度过小，表现出明显的安全-效率退化。该边界内鲁棒，边界外缺乏保障。
- **障碍物模型简化**：动态障碍物仅做脚本化运动，不主动避让或反应，未覆盖博弈性/对抗性海洋生物行为。
- **奖励权重手工调参**：无自动化搜索或敏感性分析，可能影响方法在其它平台上的迁移性。
- **世界模型的不确定性代理未经校准**：解码器方差是启发式不确定性量，非严格校准的碰撞概率或概率安全保证。
- **无真实硬件验证**：缺乏水池测试、硬件在环（HIL）或开放水域实验，工程部署成熟度有限。
- **算力开销**：密集场景下（Table III：D=15时38.0ms）可能超过50Hz实时预算，嵌入式部署需平台专门优化。控制循环中全局规划耗时较高（均值5.22ms，最大9.89ms）。
