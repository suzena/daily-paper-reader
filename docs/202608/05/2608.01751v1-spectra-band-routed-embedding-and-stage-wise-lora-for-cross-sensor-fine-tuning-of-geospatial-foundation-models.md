## 摘要
地理空间基础模型（GeoFMs）在大规模地理空间数据（如地球观测、气候和天气数据）上预训练，在多种下游任务微调时表现出良好性能。然而，将EO预训练的GeoFMs适应到实际下游数据集存在两个挑战。第一个挑战是如何处理光谱不匹配：预训练的块嵌入期望固定的输入波段集，而下游传感器可能提供不同的通道。第二个挑战是如何降低微调成本并提高效率。虽然已有工作分别针对这些挑战进行了努力，但在光谱不匹配下联合提升微调性能同时降低适应成本的研究仍不足。我们提出SPECTRA，一个参数高效的微调框架，同时解决光谱不匹配和适应成本问题。为处理光谱不匹配，SPECTRA引入带路由嵌入（BRE），将所有可用的下游波段映射到预训练GeoFM期望的波段空间。通过使用BRE，下游数据集中的所有可用波段都被利用以改进所选波段的输入，而不改变预训练的块嵌入接口。为降低适应成本，SPECTRA进一步引入分阶段可迁移性感知LoRA（ST-LoRA）微调。ST-LoRA在微调前估计分阶段可迁移性，并为各阶段分配特定LoRA秩，将可训练参数集中在目标任务可迁移性高的阶段。在三个EO预训练GeoFMs和四个下游分割数据集上，实验表明BRE通过利用所有光谱波段提升了性能，而ST-LoRA相比全微调和标准LoRA减少了可训练参数。代码可在 https://github.com/big-data-lab-umbc/SPECTRA 获取。

## Abstract
Geospatial foundation models (GeoFMs), pretrained on large-scale geospatial data such as Earth observation (EO), climate, and weather data, have shown promising performance when fine-tuned on diverse downstream tasks. However, there are two challenges of adapting EO-pretrained GeoFMs to practical downstream datasets. The first challenge is how to handle spectral mismatch: pretrained patch embeddings expect a fixed set of input bands, whereas downstream sensors may provide different channels. The second challenge is how to reduce fine-tuning cost and make it efficient. While existing work has made efforts on these challenges individually, jointly improving fine-tuning performance under spectral mismatch while reducing adaptation cost remains underexplored. We propose SPECTRA, a parameter-efficient fine-tuning framework that addresses both spectral mismatch and adaptation cost. To handle spectral mismatch, SPECTRA introduces Band-Routed Embedding (BRE), which maps all available downstream bands into the band space expected by the pretrained GeoFM. By using BRE, all available bands in the downstream dataset are utilized to improve the selected-band input without changing the pretrained patch embedding interface. To reduce adaptation cost, SPECTRA further introduces a Stage-wise Transferability-aware LoRA (ST-LoRA) fine-tuning. ST-LoRA estimates stage-wise transferability before fine-tuning and assigns stage-specific LoRA ranks, concentrating trainable parameters on the stages with high transferability for the target task. Across three EO-pretrained GeoFMs and four downstream segmentation datasets, experiments show that BRE improves performance by utilizing all spectral bands, while ST-LoRA reduces trainable parameters compared with full fine-tuning and standard LoRA. Code is available at https://github.com/big-data-lab-umbc/SPECTRA.

## 论文总结：SPECTRA

### 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 地理空间基础模型（GeoFMs）在大规模地球观测（EO）数据上预训练后，通过微调可在多种下游任务中取得良好表现。然而，将EO预训练GeoFM适配到实际下游数据集时面临两大挑战：
  - **光谱不匹配**：预训练模型的patch embedding期望固定的输入波段集（数量、顺序和光谱含义），而下游传感器可能提供不同的波段通道。常见的波段选择（band-selection）策略仅保留与预训练波段最匹配的子集，丢弃其余通道，可能丢失任务相关的重要信息。
  - **微调成本**：全量微调（Full-FT）所有预训练参数在GPU内存、优化时间和模型存储上代价高昂。参数高效微调（PEFT）方法如LoRA虽能降低开销，但标准LoRA对所有层/阶段使用统一秩，未能差异化适配各阶段的迁移性。
- 已有工作分别应对上述挑战，但**联合解决光谱失配与适配成本**的方法仍属空白。SPECTRA首次尝试在统一的参数高效微调框架下同时兼顾两者。

### 2. 论文提出的方法论

**核心思想：** SPECTRA由两大组件构成——**带路由嵌入（Band-Routed Embedding, BRE）**与**分阶段可迁移性感知LoRA（Stage-wise Transferability-aware LoRA, ST-LoRA）**。整体思路是：BRE负责将下游全部波段映射到预训练模型兼容的波段空间；ST-LoRA则根据各编码器阶段的迁移性差异差异化分配LoRA秩。

**关键技术细节：**

**（1）Band-Routed Embedding（BRE）**

- 目标是构建映射 A_θ: R^{C×H×W} → R^{K×H×W}，使输出 X_BRE 与预训练patch embedding E₀ 兼容。
- 两条路径：**选定波段路径（锚点路径）** + **全波段残差路径**。
  - 选定波段锚点：X_sel = P_sel(X)，保持与预训练输入分布接近。
  - 残差修正：X_BRE = X_sel + Δθ(X)，最终残差层零初始化，保证训练开始时与波段选择基线完全相同，不破坏预训练接口的稳定性。
- **带路由门控**：学习门控表 G ∈ R^{K×C}，G_{j,i} = 2·sigmoid(L_{j,i})，初始化为1。每个下游波段都可影响每个虚拟预训练波段（残差路径中先逐波段加权，再拼接成KC通道张量，通过共享的1×1卷积残差适配器输出K通道修正）。
- 与预训练模型连接：BRE输出 X_BRE 后，仍由原始预训练patch embedding做tokenization，因此**无需修改预训练嵌入层**，且所有下游波段均不会被硬丢弃。

**（2）Stage-wise Transferability-aware LoRA（ST-LoRA）**

- **ST-planning（预微调规划阶段）**：利用冻结特征计算各阶段LogME迁移性得分
  - q_s = LogME(Φ_s(X_sel), Y)
  - 将编码器分为S个阶段，每个阶段提取patch token特征（分类token去掉，按patch网格与标签对齐，只保留主类纯度超过阈值的patch）。
- **两种规划模式**：
  - **Transfer模式**：高迁移性阶段分配更多秩。a_s = q_s
  - **Repair模式**：低迁移性阶段分配更多秩以“修复”。a_s = max_s(q_s) - q_s
- **预算受控的秩分配**：定义参考统一秩 r_ref 和总秩预算 T_rank(r_ref) = S·r_ref；通过温度τ对信号做softmax归一化，将连续秩量化为离散候选集 R(r_ref) = {0, 4, 8, …, r_ref/2, r_ref, 2r_ref}，之后贪婪补齐预算余量。
- **嵌套LoRA实现**：各阶段秩不同，使用嵌套LoRA（最大秩适配器截断到各阶段所需秩），秩为0时该阶段LoRA禁用。

### 6. 主要结论与发现

- BRE带来显著增益：平均macro mIoU从66.36提升至69.24（**+2.88**），而直接MLP投影平均下降2.28点；BRE在前景F1上提升56/60个配置单元，平均+3.08。
- BRE的优势在**光谱失配严重时最突出**（ScaleMAE在Sen1Floods11和FireScars上的巨大提升）；在**原生匹配**场景（Prithvi-FireScars，同为6波段HLS）收益甚微。
- ST-LoRA能有效降低可训练参数：相比LoRA-32基线减少约17.1–33.6%的活跃参数，且精度保持或更优。SPECTRA整体可训练参数占比仅3.29–7.73%。
- SPECTRA在多个场景超越了Full-FT和标准LoRA，尤其在ScaleMAE-Sen1Floods11上将macro mIoU推至85.45（远超LoRA-64的77.17）。
- 自动的ST-planner秩分配效果可与**精心设计的手动秩调度**相当或更优，避免了遍历 |R|^S 种组合的搜索成本。
- 不是万能的：Prithvi-FireScars场景中SPECTRA不及LoRA-64/Full-FT，表明当预训练与下游光谱界面高度对齐时，高容量适配可能更优。

### 7. 优点

- **方法设计亮点**：
  - BRE的“锚点+零初始化残差”设计兼顾物理意义与分布稳定，避免随机投影破坏预训练接口。
  - 门控机制为每个源波段提供独立的、对所有虚拟波段可学习的贡献，结构上保证“全波段可用”。
  - ST-LoRA将LogME等低成本诊断信号引入秩分配，计算开销小，且Transfer/Repair双模式适应不同迁移情境。
  - 嵌套LoRA实现支持按阶段灵活截断，工程实现简洁高效。
- **实验设计亮点**：
  - 覆盖三种GeoFM结构、四种下游任务、三种光谱失配级别，结论具有较强泛化性。

### 8. 不足与局限

- **边界条件限制**：BRE的增益高度依赖光谱失配程度；在原生HLS场景下几乎无提升，甚至轻微的精度回退。论文承认SPECTRA是**低成本替代方案**，而非普适的更高容量替代。
- **验证广度不足**：ST-LoRA的秩规划证据最强的是Sen1Floods11；其他数据集上的自动规划模式效果较简略。对各数据集的规划模式选择（Transfer vs Repair）也缺乏更深的一致性解释。
- **未达到各数据集SOTA**：作者明确表示使用固定超参数和统一UPerNet解码器，适合诊断但不构成SOTA声明。
- **MLP基线的不稳定性**：附录显示对于ScaleMAE某些数据集，MLP可能高于基线（如Sen1Floods11 +8.35），说明随机初始化投影对光谱适配并非总是失败，BRE的稳健性优势虽明显但并非唯一可用方案。
- **非光谱辅助通道**：Landslide4Sense的DEM辅助通道作为固定输入保留，但其处理方式及交互效应未被深入分析。
