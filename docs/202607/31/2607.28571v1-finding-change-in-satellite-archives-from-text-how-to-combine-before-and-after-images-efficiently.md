## 摘要
业务化地球观测越来越需要回答诸如“找到出现新建筑的图像对”这样的查询。这意味着在前后（双时相）卫星图像对档案中进行搜索，并根据每个图像对与变化的自然语言描述的匹配程度对其进行排序。执行这种匹配的组件，即结合“前”和“后”视图的融合模块，必须在查询时对许多候选图像对运行，因此其速度在很大程度上决定了每次搜索的成本。我们对该模块的构建方式进行了受控比较。使用一个固定的图像编码器（冻结的CLIP模型）和一种适用于所有变体的训练方案，我们评估了来自三个家族的八种设计：注意力、状态空间模型（Mamba）和学习压缩（我们的时间瓶颈融合，TBF）。每种设计在两个基准（LEVIR-CC和Dubai-CC）上使用十个随机种子进行测试，因此所报告的差异具有统计基础。我们概述了三个发现：第一，一种无需训练的两阶段搜索（一个廉价的差异模型先筛选候选，然后注意力融合重新排序）在LEVIR-CC上匹配或超过全融合的召回率，同时将查询成本降低$10$-$15$倍，在Dubai-CC上R@1/R@5相当；第二，Mamba的线性时间扫描在理论上很有吸引力，但在视觉Transformer典型的图像块数量（$L=196$）下并未带来速度优势：扫描受限于内存带宽，而注意力能很好地映射到并行硬件上；第三，压缩融合表示（TBF）使参数减少$2.3$倍、延迟减少$1.6$倍，且仅带来$0.007$的仅变化BLEU-1代价，尽管更激进的压缩会悄悄丢弃与变化相关的细节，而这些细节是聚合指标无法揭示的。

## Abstract
Operational Earth observation increasingly calls for answering queries such as ``find the image pairs where a new building appeared.'' This means searching an archive of before-and-after (bi-temporal) satellite image pairs and ranking each pair by how well it matches a natural-language description of the change. The component that performs this match, the fusion module that combines the ``before'' and ``after'' views, must be run at query time across many candidate pairs, so its speed largely sets the cost of every search. We present a controlled comparison of how to build that module. Using one fixed image encoder (a frozen CLIP model) and one training recipe for all variants, we evaluate eight designs drawn from three families: attention, state-space models (Mamba), and learned compression (our Temporal Bottleneck Fusion, TBF). Each design is tested on two benchmarks (LEVIR-CC and Dubai-CC) with ten random seeds, so the reported differences are statistically grounded. We outline three findings: first, a training-free two-stage search (a cheap difference model that shortlists candidates, followed by attention fusion that re-ranks them) matches or exceeds full-fusion recall on LEVIR-CC while cutting query cost $10$-$15\times$, with comparable R@1/R@5 on Dubai-CC; second, the linear-time scan of Mamba, attractive on paper, gives no speed benefit at the patch counts typical of vision transformers ($L{=}196$): the scan is limited by memory bandwidth, whereas attention maps cleanly onto parallel hardware; and third, compressing the fused representation (TBF) reduces parameters by $2.3\times$ and latency by $1.6\times$ for a change-only BLEU-1 cost of $0.007$, although more aggressive compression quietly discards change-relevant detail that aggregate metrics fail to reveal.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 地球观测（EO）档案规模急剧增长，人工筛查已不可行，许多关键信息存在于**双时相（bi-temporal）图像**中，而非单一图像。
- 实际业务需求表现为自然语言查询，例如“找到沿路出现新建筑的图像对”。这类**基于文本的变化检索**（Text-Based Change Retrieval）需要将“变化描述”与“前后图像对”进行匹配。
- 核心瓶颈在于：在部署场景中，视觉骨干网络可在数据入库时离线运行一次（摊销成本），而**融合模块（fusion module）必须在查询时对每个候选图像对运行**，因此其延迟和内存开销直接决定搜索成本，尤其在地面资源受限平台上。
- 现有工作（如 Text-ITSR）虽将 CLIP 范式扩展至双时相检索，但**缺乏对融合模块计算效率的系统性研究**。本文正针对这一空白，进行受控对比分析。

## 2. 论文提出的方法论

**核心思想：**

在固定编码器与统一训练方案的前提下，系统比较三类融合架构家族（注意力、状态空间模型 Mamba、学习压缩 TBF），探究**效率与精度的最佳权衡点**，并检验理论复杂度优势能否转化为实际墙钟时间收益。

**关键技术细节：**

1. **统一框架**（保证可比性）：
   - 冻结 CLIP ViT-B/16 编码器，提取 patch 特征 \(X_1, X_2 \in \mathbb{R}^{L \times D_{in}}\)（\(L=196\), \(D_{in}=768\)）。
   - 投影至统一宽度 \(D=320\) 后再送入融合模块。
   - 视觉嵌入 \(v_i\) 与文本嵌入 \(t_j\) 的相似度采用余弦分数 \(s_{ij}\)。
   - 训练目标为标准对称 InfoNCE 对比损失。

2. **三类八种融合设计**：
   - **简单基线**：Subtraction（像素差 + 线性投影）、MLP Fusion（通道拼接 + 两层 MLP）。
   - **注意力家族**：
     - Concatenation Transformer：沿通道轴拼接双时相特征（\(L \times 2D\)），经标准 Transformer 处理；宽度翻倍使参数量膨胀至 13.05M。
     - TFF（Text-ITSR 的融合模块）：在差分特征与原始双时相特征之间做交叉注意力。
   - **压缩家族（TBF，本文提出）**：
     - 采用“先拼接再降维”（concat-then-reduce）模式：MLP（Linear \(2D \to D\) + ReLU + Linear \(D \to D\) + LayerNorm）先将拼接特征压回宽度 \(D\)，再送入标准 Transformer 交互。
     - 因线性层和 FFN 成本随宽度平方增长，该设计使参数和计算减少约 \(4\times\)，同时保留全局自注意力。
   - **SSM 家族（Mamba）**：三种变体——Concatenation Mamba（宽度 2D）、Bottleneck Mamba（压缩后宽度 D）、Interleaved Mamba（时间 token 交错为长度 2L 的序列）。

3. **两阶段级联检索**（无需训练）：
   - 第一阶段：使用 Subtraction 模型（0.04 ms/对）对全部候选对快速排序，筛出 top-N 短名单。
   - 第二阶段：用注意力融合模型（TBF 或 Concatenation Transformer）对短名单重新排序。
   - 该级联设计借鉴经典信息检索（cascade ranking）思想，候选对需同时通过差分信号和全融合的打分，产生隐式集成效应。

## 6. 论文的主要结论与发现

1. **两阶段级联搜索极为有效**：LEVIR-CC 上 N=25 时，级联匹配或超越全融合召回，查询成本降低 **10–15×**（TBF 89 ms vs 907 ms；CT 96 ms vs 1466 ms），且所有 10 个种子均一致（配对 p=0.002）；Dubai-CC 上质量持平、成本降 2.6×。速度提升随检索库规模增大趋近每对 12–19× 的上限。

2. **Mamba 线性复杂度在 \(L=196\) 无实际收益**：参数最少的 Interleaved Mamba（2.27M）延迟反而比 TBF（5.73M）高 28%。原因是选择性扫描为顺序、内存带宽受限操作，而注意力可映射到高度并行的张量核心矩阵乘。序列长度扫描显示 Mamba 需 \(L \gtrsim 400\)（两帧以上）才超越注意力，至 \(L=6272\) 才可达 10× 加速——适合长多时相序列，不适合标准瓦片尺寸。

3. **TBF 是效率-质量的最佳平衡点**：相比 Concatenation Transformer，参数减少 **2.3×**、延迟降低 **1.6×**，仅付出 0.007 的 change-only BLEU-1 代价（不可配对检出，p=0.08；可配对检出 p=0.04）。但**激进的压缩会静默丢弃变化相关细节**，聚合指标（如完整集 BLEU-1）无法揭示，只有在 change-only 子集才可见。

4. **注意力仍是默认选择**：Concatenation Transformer 在 LEVIR-CC 语义指标和严格 Recall 上均最优，但优势有限；Pareto 前沿仅包含简单基线、TBF 和 CT，Mamba 与 TFF 均被支配。

5. **小数据体制下容量收益无法兑现**：Dubai-CC 仅 300 训练对时，所有模块聚类在噪声范围内（变化子集 BLEU-1 差 ≤0.02）。

## 7. 优点
