## 摘要
深度子空间聚类在涉及多元时空数据的应用中扮演着关键角色，例如海冰监测、疾病传播分析以及追踪神经退行性疾病的随时间演变。尽管近期取得了进展，但现有方法主要依赖几何自表达性，假设静态子空间结构，并且常常无法捕捉复杂时空系统中固有的因果依赖、局部空间交互和长程时间动态。为应对这些局限，我们提出了一种新颖的因果对抗子空间聚类（CASC）框架，用于发现高维时空数据中演变的潜在状态。CASC将受U-Net启发的深度对抗聚类架构与堆叠的FAConvLSTM层相结合，在保留空间和时间结构的同时学习鲁棒的潜在表示。引入了基于图注意力变换器的自表达网络，以联合建模局部空间关系、全局依赖和长程时间交互。此外，我们提出了两个新的学习目标：（1）因果子空间保持损失，将自表达系数与潜在因果关系对齐，促使聚类反映潜在的因果过程而非简单的特征相似性；（2）动态时间子空间演化损失，捕捉非平稳环境中演变的子空间结构和时间状态转变。这些组件共同将深度子空间聚类从相关性驱动的范式转变为因果时间状态发现框架。

## Abstract
Deep subspace clustering plays a critical role in applications involving multivariate spatiotemporal data, such as sea ice monitoring, disease spread analysis, and tracking neuro-degeneration over time. Despite recent advances, existing methods primarily rely on geometric self-expressiveness, assume static subspace structures, and often fail to capture causal dependencies, local spatial interactions, and long-range temporal dynamics inherent in complex spatiotemporal systems. To address these limitations, we propose a novel Causal Adversarial Subspace Clustering (CASC) framework for discovering evolving latent regimes in high-dimensional spatiotemporal data. CASC integrates a U-Net-inspired deep adversarial clustering architecture with stacked FAConvLSTM layers to preserve spatial and temporal structure while learning robust latent representations. A graph attention transformer-based self-expressive network is introduced to jointly model local spatial relationships, global dependencies, and long-range temporal interactions. Furthermore, we propose two new learning objectives: (1) a Causal Subspace Preservation Loss that aligns self-expression coefficients with latent causal relationships, encouraging clusters to reflect underlying causal processes rather than simple feature similarity, and (2) a Dynamic Temporal Subspace Evolution Loss that captures evolving subspace structures and temporal regime transitions in nonstationary environments. Together, these components transform deep subspace clustering from a correlation-driven paradigm into a causal-temporal regime discovery framework.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 核心思想
提出 **CASC（Causal Adversarial Subspace Clustering）** 框架，将生成对抗网络（GAN）、子空间聚类、因果关系发现、时间动态建模统一在一个端到端的架构中。通过一个生成器与一个判别器的对抗训练，使学习到的潜在表示既忠实于数据的时空结构，又符合因果一致性与子空间几何特性。

### 关键技术细节

**（1）生成器（Generator, G）**，包含四个部分：
- **FAConvLSTM 编码器**：采用U-Net下采样结构，五层FAConvLSTM层捕捉时空相关性，配合残差时间块与时空池化，逐步将高维输入（B×T×H×W×C）压缩为紧凑潜在表示。每层输出保留为跳跃连接（skip connection）供解码器使用。
- **双向时间图注意力变换器（Bi-TGAT）瓶颈**：对潜在表示进行patch化处理，以降低图规模；然后对每个时间步的节点特征通过前向/后向时间相邻帧计算注意力系数（公式3），聚合得到上下文化表示（公式4），最后池化为每个时间步的嵌入 zt。
- **逐时间步聚类头**：采用DEC风格的Student-t分布分配（公式5），引入温度参数 τ 控制分配的锐度，并加入批量KL散度与互信息正则避免模式坍缩。
- **自表达时序子空间层 + 解码器**：解码器镜像编码器结构，通过跳跃连接重建输入，重建损失为 Lrec = ‖X̂ − X‖²₂。

**（2）两个新损失函数**：

- **因果子空间保持损失（Causal Subspace Preservation Loss, CSP）**：
  - 传统自表达损失：Lself = ‖Z − ZC‖²_F + λ₁‖C‖_p
  - 该文引入因果一致性目标：Lcausal = ‖A_causal − CCᵀ‖²_F，其中 A_causal 为通过因果发现方法（如 Neural Granger Causality、PCMCI+、Transfer Entropy 或 Convergent Cross Mapping）估计的因果邻接矩阵。
  - 完整CSP损失：LCSP = ‖Z − ZC‖²_F + λc ‖A_causal − CCᵀ‖²_F + λr ‖C‖_p
  - 这一设计的含义是：使属于同一物理过程的样本被分到同一子空间，而不仅仅依赖几何相似性。

- **动态时间子空间演化损失（Dynamic Temporal Subspace Evolution Loss, DTSE）**：
  - 将静态自表达矩阵扩展为时间相关序列 C = {C₁, C₂, …, C_T}
  - 单时间步重建损失：L_self^(t) = ‖Zt − ZtCt‖²_F
  - 时间一致性正则：LDTSE = Σ_{t=2}^T ‖Ct − C_{t−1}‖₁（或KL散度变体）
  - 完整动态目标：Ldynamic = Σ_t L_self^(t) + λd LDTSE
  - 该设计允许子空间随时间渐变，同时抑制突变的簇切换。

**（3）能量基时间子空间判别器（Energy-Based Temporal Subspace Discriminator, SETD）**：
- 不再使用传统深度二分类判别器，而是学习一组簇特定的正交子空间基 U = {U₁, …, U_K}
- 计算投影残差：rk = z − UₖUₖᵀz，能量定义为 Ek(z) = ‖rk‖²₂
- 整体能量为 E(z) = min_k Ek(z)
- 训练使用 margin-based hinge loss：Lhinge = (1/N) Σ max(0, E_real − E_fake + m)
- 辅以正交性正则 Lorth = Σ ‖UₖᵀUₖ − I‖²_F 与子空间分离正则 Lsep = Σ_{i<j} ‖UᵢᵀUⱼ‖²_F
- 相比DASC的深层判别器，SETD参数量仅O(Kdr)，更轻量、更稳定。

**（4）整体优化目标**：
Ltotal = λ₁Lrec + λ₂Ladv + λ₃Lcluster + λ₄Lself + λ₅LCSP + λ₆LDTSE

**（5）训练流程**：
- 异步执行生成器步骤（更新编码器、Bi-TGAT、聚类中心、自表达参数）和判别器步骤（更新 {Uₖ}）
- 温度 τ 初始较大后逐步退火，平衡系数逐步增加，自表达层可在预热后启用
- 推理时取 argmax q_t 作为硬标签，也可通过自表达系数构建亲和矩阵并应用谱聚类细化

## 6. 论文的主要结论与发现

- **主实验结论**：CASC在三个数据集上一致地取得最优或最接近最优的性能：
  - **ERA5**：SIL最高（0.3268）、DB最低（1.5009）、RMSE最低（13.5158）、I-CD最大（7.4839）。
  - **CARRA**：SIL最高（0.2767）、DB最低（1.5089）。
  - **NCAR**：SIL最高（0.6541）、CH最高（868.7555）、RMSE最低（3.1180）。
- CASC在多个互补指标上同时取得最佳表现，表明其能够更好地平衡簇内紧凑性与簇间分离性，而基线方法常常只在单一指标上突出（如DSC的CH、DASC的I-CD）。
- 图3可视化分析表明，CASC能识别出一年中约120天的稳定持久状态（Cluster 1占优势）以及频繁转换的过渡阶段，说明其能够捕捉时间状态的持久性与瞬时性。
- **消融实验结论**：
  - CSP单独使用可提高紧凑性与分离性，但处理复杂时间动态能力有限；
  - DTSE单独使用产生最低方差（0.1032），时间平滑性最强但判别力较弱；
  - SETD是三个组件中单独贡献最大的（SIL 0.2827、DB 1.6941、CH 99.9202）；
  - 三者联合（完整CASC）效果最佳，证明组件间互补性明显。
- **总体发现**：注意力引导机制与能量基对抗子空间建模的结合，能够从复杂气候再分析数据中学习到更具判别力、时间一致的潜在表示。

## 7. 优点

### 方法设计亮点
- **首次将因果一致性显式融入自表达子空间聚类**：CSP损失通过因果邻接矩阵约束自表达系数，使聚类反映物理驱动机制而非表面相似性，增强了科学可解释性——这是该文最核心的原创贡献。
