## 摘要
近年来，大语言模型和多模态模型的进展已将遥感（RS）处理从简单的感知模型推向旨在解决复杂、长时程遥感任务的智能体系统。然而，现有系统通常依赖整体式决策框架，难以适应遥感任务多阶段、相互依赖的特性。这种集中式方法导致任务执行不稳定、工具使用错误以及跨阶段错误传播等挑战。为解决这些问题，我们提出了HiRS-Agent，一种用于长时程遥感任务求解的分层多智能体系统。HiRS-Agent采用两层协作架构：管理层负责动态路由、步骤级验证、重新规划和终止控制，而专家层根据遥感工作流组织领域专用工具，并负责子任务推理和工具执行。为进一步增强系统能力，我们引入两阶段监督微调策略和验证引导的分层强化学习阶段，以联合优化协调和工具使用策略。在Earth-Agent Benchmark和ThinkGeo上的实验表明，HiRS-Agent显著提升了长时程工具使用能力和最终任务正确性，证明了结构化多智能体协作对于可靠遥感智能体的有效性。代码公开于https://github.com/IntelliSensing/HiRS-Agent。

## Abstract
Recent advances in large language models and multimodal models have pushed remote sensing (RS) processing from simple perception models to agentic systems designed to tackle complex, long-horizon RS tasks. However, existing systems often rely on monolithic decision-making frameworks, which fail to accommodate the multi-stage, interdependent nature of RS tasks. This centralized approach leads to challenges such as unstable task execution, incorrect tool usage, and error propagation across stages. To address these issues, we propose HiRS-Agent, a hierarchical multi-agent system for long-horizon RS task solving. HiRS-Agent adopts a two-level collaborative architecture: the Manager Layer handles dynamic routing, step-level verification, replanning, and termination control, while the Specialist Layer organizes domain-specific tools according to the RS workflow and is responsible for subtask reasoning and tool execution. To further enhance the system's capability, we introduce a two-stage supervised tuning strategy and a verification-guided hierarchical reinforcement learning stage to jointly optimize coordination and tool-use policies. Experiments on Earth-Agent Benchmark and ThinkGeo show that HiRS-Agent substantially improves long-horizon tool-use capability and final-task correctness, demonstrating the effectiveness of structured multi-agent collaboration for reliable RS agents. The code is publicly available at https://github.com/IntelliSensing/HiRS-Agent.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：随着大语言模型（LLM）与多模态大语言模型（MLLM）的快速发展，遥感（Remote Sensing, RS）领域的分析模式正从传统的单次感知模型（如视觉问答、场景理解等）向具备多步推理与工具调用能力的智能体化系统演进。真实世界的遥感任务（例如洪水制图、土地利用变化分析）通常流程长、阶段多，并存在强烈的上下游依赖关系，需要跨步骤的规划、工具执行与中间结果判读。
- **核心问题**：现有遥感智能体多从通用智能体范式直接迁移，采用单一化（Monolithic）集中决策框架，无法匹配遥感任务的内在阶段化结构，从而导致三大“错配”：
    1. **工作流错配（Workflow Mismatch）**：缺乏对遥感标准化流程（光谱解析→物理反演→统计分析）的显式建模。
    2. **知识错配（Knowledge Mismatch）**：通用大模型缺乏遥感领域专业机理知识（物理约束、光谱规则、数据处理流程等）。
    3. **控制错配（Control Mismatch）**：缺少中间步骤的状态验证与失败恢复机制，导致早期错误跨阶段传播。
- **研究含义**：本文主张解决长时程遥感任务可靠性的核心不仅在于模型规模，更在于显式建模遥感工作流的结构化多智能体协作机制，以实现可靠、可控的复杂任务求解。

## 2. 论文提出的方法论

### 2.1 核心思想：分层多智能体协作架构

HiRS-Agent 采用“管理层-专家层”的两层协作架构，将任务求解从通用决策转变为流程化、专业化的执行链。

- **管理层（Manager Layer）**：由编排智能体（Orchestrator Agent, OA）构成，充当核心控制器，负责全局工作流管理。
    - **规划与动态路由**：根据用户指令和输入数据，分解子目标，并动态选择最合适的下一阶段专家智能体（式2）。
    - **全局记忆建模**：维护结构化全局状态（式1），包括指令、输入数据、历史记忆单元与动态约束，突破短视决策局限。
    - **历史感知的步骤级验证**：利用全球状态和检索式记忆对专家返回的中间结果执行三类校验——①Schema有效性、②子目标一致性、③遥感约束（物理/光谱/统计合理性）满足度（式3-4）。输出 `{pass, uncertain, fail}` 三级判定。
    - **验证引导的自适应控制**：根据验证结果动态调整：`FAIL`触发重规划/工具修复/路由变更；`UNCERTAIN`触发交叉验证或多路径推理；`PASS`则状态入库并进入下一步。形成“记忆→验证→重规划”的闭环。

### 2.2 专家层（Specialist Layer）：按遥感工作流组织工具

按遥感处理链条将专家智能体分为三类，每个专家面向有限的、特定领域的工具子集：

- **表层解析智能体（SPA）**：负责目标检测、分割、光谱指数提取等场景解析，对应流程中的“光谱解析”环节。
- **物理反演智能体（PRA）**：负责物理量级反演和定量产品生成（如地表温度），关注单位、辐射定标、大气纠正约束。
- **统计分析智能体（SAA）**：负责统计检验、数据聚合、时间序列分析及报告输出，对应“高层决策支撑”环节。

这三类专家与遥感工作流的三个核心功能阶段（光谱解析→物理/信息检索→统计分析）对齐，通过工具空间剪枝降低跨领域混淆。

### 2.3 两阶段监督微调：专家到工作流对齐调优（Expert-tuning）

- **阶段一（专家知识注入）**：构建海量结构化遥感知识语料库（3个L1主题、11个L2模块、28个L3领域，分类知识、1,583个语义知识块），形成 RS-EXPERT 语料集；以此为基础训练基础模型，增强其遥感物候、辐射传输、影像处理等领域的专业知识容量。
- **阶段二（工作流对齐）**：从真实多智能体应用日志中提取工作流流程序列，构建 684 个工作流 MCQ + 309 个工作流排序样本，训练模型将高层任务意图与可执行的工具调用序列对齐。

### 2.4 验证引导的分层强化学习（VG-HRL）

在专家微调基础上引入分层强化学习，联合优化全局协调策略与局部工具执行策略。

- **分层奖励设计**：
    - **管理层奖励**（`R_mgr`，式5）：基于路由正确性、最终任务成功度和轨迹长度惩罚组成轨迹级反馈。
    - **专家层奖励**（`R_spec`，式6）：采用**领域感知分级归一化奖励**，将工具选择错误分为三级（幻觉工具/域内错误工具/正确工具），区分不同“错误程度”，替代传统的二值失败判定；在正确的工具层上额外加入参数质量评估分数（`R_args`），改进局部执行的信用分配问题。
- **角色感知分组优化**：
    - 管理层在同一任务的多次 rollout 间计算相对优势（式7）以估计全局协调优势；
    - 专家层则在同一（任务, 步骤号）的组内计算相对优势（式8），保证逐步工具比较的公平性。
- **联合优化**：采用参数共享单骨干（Qwen3 基座 + LoRA），子任务专家与管理层由角色特定 Prompt 区分；高层次对损失（式9）进行联合反向传播，管理/专家损失权重 λ=0.5 均衡更新。该部分通过 GRPO 实例化实现，完整算法流程见 Algorithm 1。

## 6. 论文的主要结论与发现

- HiRS-Agent 在 Earth-Bench 与 ThinkGeo 上均一致显著超越裸的 Qwen3-4B/8B 基座（例如在 Earth-Bench 中使 4B 规模模型的 Accuracy 从 15.73/10.08 提升至 43.95/45.56；在 ThinkGeo 的 **Ans.** 最终答案指标上创下所有方法中的最优记录）。
- 系统增益主要来自层次化专业分工、验证引导控制与后 SFT 强化学习优化，而非仅仅提升模型参数量。
- 消融结果证明**层次化架构**与**步骤级验证**分别提供了独特且互补的增益（去验证后 Exact 下降 11.30/12.43 个百分点）。
- Expert-tuning 能在显著增强遥感知识的同时基本保持乃至不损害通用推理能力（见 MMLU-Redux 的 66.57→66.80 结果），仅在大规模指令跟随上出现适度下降，显示了良好的专业—通用权衡。
- **关键结论**：对于可靠长时程任务执行，显式建模工作流结构、约束可回溯的中间验证和逐步专业化分工比盲目扩大模型尺度更为关键。即便轻量 4B 开源模型辅以结构化系统设计，也可在特定任务上超越最强的闭源模型。

## 7. 优点

- **架构创新**：将遥感多阶段任务的内部依赖关系显式引入智能体设计，符合领域实际问题（上游错误影响下游推断），非通用对话式多智能体模板的简单套用；
- **验证机制**：首个将“物理/光谱/统计约束校验”物化进步骤级验证判据（式4）的 RS 智能体系统，且有 `uncertain` 中间态，比平时二值验证在设计上更接近专家实际行为；
- **强化学习分层奖励设计精细**：式(6) 的三级工具错误分类与逐步比较机制（式8）有效回避了长程稀疏奖励下学习信号淹没问题；
- **训练数据闭环**：从专业教科书知识抽取到多智能体日志事件提取流程，构建了一个可用于学术小规模泛化考验的高质量公开评测基准；
- 通用能力验证充分、消融严谨，且代码公开，利于复现。

## 8. 不足与局限

- **实验规模局限性**：主实验只验证了 4B 与 8B 轻量级基座模型。对更大开源模型（如 32B、72B 甚至百B级 MLLM）提升幅度是否保持同样增益，并未提供证据；无法排除超大模型可“自行涌现”出同等工作时序组织的可能性；
- **真实极端环境覆盖**：全部模拟测试均基于规范化的基准工具集（120 个接口）。未考虑多源数据缺失、噪声轨道数据、模型本身视觉输入误读等非工具故障场景下的恢复能力；
- **强化学习训练细节不透明**：对统一架构中各角色间的偏差漂移控制、基础 RL 稳定性（如 KL 系数、滚动生成长度截断策略），安全恢复循环的触发频率与计算开销，正文及摘要有意简化处理；
- **验证器是否本身不可靠的问题**：全新模型承担验证功能时，在未见任务上自身可能产生幻觉判定，流程缺少自动化二次监督或人机反馈机制；
- **通用指令跟随能力受损**：在 Multi-IF 上相比基础版本下降 2.82（58.35→55.53），暗示领域注入对大模型通用意图遵循，有时轻微损伤，有关注但尚未完全解决；
- **推理开销成本未量化**：与单智能体相比，多层智能体的 token 成本、调用时延的中位数；两层循环及失败重规划所带来的额外执行时间未被计算在效率指标中，可能导致实际系统经济性评估失真。
