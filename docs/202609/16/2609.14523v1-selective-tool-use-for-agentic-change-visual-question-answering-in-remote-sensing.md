## 摘要
变化视觉问答（Change VQA）需要理解双时相遥感图像中的语义变化。尽管视觉语言模型（VLMs）在该任务上已表现出良好性能，但在回答需要显式转移统计、面积测量或空间信息的问题时仍不可靠。为解决这一局限，我们提出一种选择性工具使用框架，其中单个 VLM 可以直接回答，也可以调用确定性的变化分析工具来获取问题特定的证据。具体而言，所选工具在双时相语义图上运行，并返回结构化观测结果，同一个 VLM 利用该结果生成最终答案。为支持该框架，我们构建了 CDVQA 的工具增强扩展，涵盖八个问题族以及用于转移、空间和时间分析的三种工具。工具使用监督和观测结果均从原始语义标注中自动推导，无需额外人工标注。随后，我们使用低秩适配（LoRA）对 Qwen3.5-4B 进行适配，以联合学习直接回答、工具调用和基于证据的回答。在 7,164 个测试问题上的实验表明，使用参考语义图的选择性工具使用将总体准确率从 73.77% 提升至 88.79%，平均问题族准确率从 69.11% 提升至 89.65%。当语义图自动预测时，该框架达到 77.47% 的总体准确率和 75.06% 的平均问题族准确率。这些结果证明了问题特定语义证据对 Change VQA 的益处，同时凸显了语义预测质量对最终性能的影响。代码和工具增强标注将在 https://github.com/yakoubbazi/ToolChangeVQA 公开提供。

## Abstract
Change visual question answering (Change VQA) requires understanding semantic changes across bi-temporal remote sensing images. Although vision language models (VLMs) have shown promising performance on this task, they remain unreliable when answering questions that require explicit transition statistics, area measurements, or spatial information. To address this limitation, we propose a selective tool use framework in which a single VLM either answers directly or invokes a deterministic change analysis tool to obtain question specific evidence. Specifically, the selected tool operates on bi-temporal semantic maps and returns a structured observation, which the same VLM uses to generate its final answer. To support this framework, we construct a tool augmented extension of CDVQA covering eight question families and three tools for transition, spatial, and temporal analysis. Tool use supervision and observations are derived automatically from the original semantic annotations, without additional manual labeling. We then adapt Qwen3.5-4B using Low Rank Adaptation (LoRA) to jointly learn direct answering, tool invocation, and evidence conditioned answering. Experiments on 7,164 test questions show that selective tool use with reference semantic maps improves overall accuracy from 73.77% to 88.79% and average family accuracy from 69.11% to 89.65%. When the semantic maps are predicted automatically, the framework achieves 77.47% overall accuracy and 75.06% average family accuracy. These results demonstrate the benefit of question-specific semantic evidence for Change VQA, while highlighting the influence of semantic prediction quality on the resulting performance. Code and tool-augmented annotations will be made publicly available at https://github.com/yakoubbazi/ToolChangeVQA.

# 论文总结：面向遥感智能体式变化视觉问答的选择性工具使用

## 1. 核心问题与研究动机

- **任务背景**：变化视觉问答（Change VQA）要求模型对双时相、已配准的遥感影像进行自然语言交互式推理，不仅识别变化区域，还要回答受影响的地物类别、类别转移关系、变化范围与位置等问题。CDVQA 是该任务的代表性基准。
- **现存瓶颈**：尽管通用视觉语言模型（VLM）经适配后在 Change VQA 上表现优于多种专用方法，但其准确率在不同问题类型间严重不均衡：
  - 变化是否存在、增加/减少等问题，可依赖视觉上显而易见的差异回答；
  - 但涉及**精确比例、类别转移统计、面积测量、空间位置关系**的问题则明显困难。例如"某类别变化占比"需要比较受影响面积与总面积，"主要转移去向"需要在多个转移量之间比较排序——直接视觉作答并不会显式执行这些计算。
- **核心研究问题**：VLM 能否学会主动请求**问题特定的语义证据**，并利用该证据改进回答？
- **整体含义**：作者提出"选择性工具使用"（Selective Tool Use）框架，让同一个 VLM 在"直接作答"与"调用确定性分析工具"之间自主选择，从而把需要显式测量的推理外包给可验证的确定性计算，同时保持端到端可训练。

## 2. 方法论

### 2.1 核心思想

- 给定双时相影像对 $(I^{(1)}, I^{(2)})$ 与问题 $q$，单个 VLM $f_\theta$ 先产生**第一次响应** $r_1$：
  - 要么是直接答案 $\hat{y}$（交互终止）；
  - 要么是结构化工具调用 $c=(\tau, a)$，其中 $\tau \in \mathcal{T}$ 为工具名，$a$ 为参数。
- 工具在**外部双时相语义图**上执行确定性计算，返回结构化观测 $o = T_\tau(\tilde{S}^{(1)}, \tilde{S}^{(2)}; a)$。
- 同一个 VLM 结合原始输入、工具调用与观测，生成最终答案 $\hat{y} = f_\theta(I^{(1)}, I^{(2)}, q, c, o)$。
- **关键设计约束**：
  - **至多一次工具调用**，无多步链式调用；
  - **不引入独立的路由网络**，响应模式选择由同一个 VLM 完成；
  - **语义图不作为视觉输入提供给 VLM**，仅存在于工具侧，VLM 只接收结构化观测文本。

### 2.2 工具注册表（三类确定性工具）

| 工具 | 功能 |
|---|---|
| Transition（转移） | 类别转移矩阵、变化/稳定面积统计 |
| Spatial（空间） | 新出现区域的空间分布（如四象限占比） |
| Temporal summary（时间摘要） | 场景级变化模式与成因摘要 |

- 三类工具均在同一地物标签空间上运行，标签体系为六类：非植被地表（NVG_surface）、建筑、操场、水体、低矮植被、树木。

### 2.3 语义证据的两种来源

- **参考设定（reference）**：工具使用真值语义图，属"oracle 证据"，用于评估交互协议本身，**不代表完全自动的图像到答案流程**。
- **预测设定（predicted）**：训练文献 [9] 的语义变化检测模型，从影像对估计双时相语义图。该模型提取多尺度双时相特征，经级联门控解码器逐步融合，预测各时相的语义状态。
- 两种设定下工具定义与交互协议**完全不变**，因此可干净地度量"证据质量下降"带来的影响；框架不绑定特定分割模型。

### 2.4 工具增强指令微调

- 每条训练样本为一条轨迹：直接回答轨迹，或工具辅助轨迹（含工具调用 + 观测 + 最终答案）。
- 目标响应模式与工具分配遵循**构建基准时固定的"问题族—工具"策略**。
- 工具观测由参考语义图按公式自动计算并插入对话；观测 token **不参与损失**，仅作为上下文。
- 训练目标为仅对助手响应 token 的自回归交叉熵损失：
  - $L(\theta) = -\frac{1}{|A|}\sum_{t \in A} \log p_\theta(z_t \mid x, z_{<t})$，
  - 其中 $A$ 为受监督的助手 token 位置（直接轨迹中为答案 token；工具轨迹中为工具调用与最终答案 token）。
- **适配方式**：LoRA 仅施加于 LLM 解码器中选定的注意力投影；视觉编码器、多模态对齐模块及全部预训练权重冻结。由此**联合监督响应模式选择、工具调用与基于证据的回答**。

## 6. 主要结论与发现

- **直接作答明显不足**：OA 73.77%、AA 69.11%；F4（比例）50.34%、F5（最大/最小变化）47.20%、F6（空间定位）52.42% 为最弱环节。
- **参考语义证据带来大幅提升**：OA → **88.79%**（+15.02 点），AA → **89.65%**（+20.54 点）；六个工具依赖族全面提升，F3 69.06%→97.77%、F4 50.34%→99.83%、F6 52.42%→99.76%、F8 达 100.00%。
- **工具调用本身不是瓶颈**：模型能稳定遵循预定工具策略并正确执行工具；工具依赖问题上的"证据条件作答"准确率为 91.56%，说明残差错误主要发生在**证据解读阶段**而非调用阶段。
- **自动预测语义图下收益仍存在但缩水**：OA **77.47%**、AA **75.06%**（相对直接作答 +3.70 / +5.95 点）；最大增益在 F6（52.42%→66.46%）、F8（80.38%→93.46%）、F4（50.34%→63.40%）。
- **对证据质量敏感**：参考→预测的 OA 差距达 **11.32 点**；F4（99.83%→63.40%）与 F6（99.76%→66.46%）降幅最大，但仍显著高于直接作答基线；F8 较稳健（100.00%→93.46%）。
- **持续难点**：F5（最大/最小变化）即使有参考证据也仅 47.20%→59.51%，因其需要比较并排序多个转移量而非解读单一测量值。
- **预测器性能**（Table IV）：mIoU 73.08%、SeK 25.42%、$F_{scd}$ 65.29%、OA 87.38%，表明语义预测质量是端到端性能的关键制约。

## 7. 优点

- **问题定位精准**：把 VLM 在 Change VQA 上的失败明确归因于"缺少显式测量"，而非笼统的视觉理解不足，动机与方案高度对应。
- **架构简洁优雅**：单一 VLM 同时承担路由、工具调用与作答，**无需独立路由网络**，至多一次工具调用，工程复杂度低；语义图保持外部，避免污染视觉输入。
- **确定性工具 + 结构化观测**：把比例、转移、空间分布等计算交给可验证的确定性算子，观测为结构化文本，可解释性与可复现性强。
- **零额外人工标注**：工具调用监督、参数与观测全部由原语义标注自动推导，显著降低数据构造成本，且基准可公开复用。
- **双证据设定设计巧妙**：参考 vs 预测的对照直接量化了"协议上界"与"实际可达性能"的差距，为后续工作指明了改进方向（提升语义预测质量）。
- **细致的解耦分析**：区分"工具选择/执行"与"证据条件作答"，得出 91.56% 的证据条件准确率，准确指出错误来源。

## 8. 不足与局限

- **评测覆盖有限**：仅一个自建数据集（CDVQA 扩展）与一个 4B 规模骨干，缺少跨数据集、跨骨干、跨任务（如变化描述、变化检测）的泛化验证。
- **缺乏横向基线**：未与 Change-Agent、RS-Agent 等 agentic 框架，或专用 Change VQA 方法比较，难以判断相对优势幅度。
- **无消融与敏感性分析**：LoRA 超参、适配层位置、工具粒度、允许调用次数、是否提供语义图可视化等关键设计均未被系统检验。
- **"选择性"的自主性受限**：工具使用策略在基准构建阶段按问题族固定，训练为监督模仿，**并未验证模型在开放问题下的自主路由能力**；也未考察错误路由的鲁棒性。
- **单步交互限制**：至多一次工具调用、无多步推理与工具组合，对需要多工具协同或迭代验证的复杂问题（如 F5 的比较排序）能力受限。
- **对语义预测质量的强依赖**：端到端性能与参考设定相差 11.32 点，F4/F6 在预测图下下降逾 30 点，实际部署效果高度受制于分割模型；而预测器本身 SeK 仅 25.42%，变化类别的分离能力偏弱。
- **报告与可复现性细节不足**：未报告训练时长、随机种子、多次运行方差或统计显著性；参考设定为 oracle，不能作为真实系统性能宣称。
- **潜在偏差风险**：基准构造规则由作者定义，问题族分布（44% 直接 / 56% 工具依赖）与答案空间（如比例被离散为区间标签）可能简化任务难度；"100% 准确率"族（F8）提示部分问题族可能过于模板化。
- **应用限制**：框架假定存在共配准的双时相影像与统一标签空间下的语义图；在标签体系不一致或缺乏可靠语义预测源的真实场景中难以直接迁移。
