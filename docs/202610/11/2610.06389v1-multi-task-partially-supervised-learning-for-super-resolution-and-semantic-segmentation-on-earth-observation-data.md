## 摘要
超分辨率与语义分割已知能够相互受益，尤其在地球观测场景中。然而，在联合模型中学习这两项任务通常需要同时具备两项任务的标注，这既不切实际又成本高昂。本文研究面向这两项任务的多任务部分监督学习范式，其中假设每个样本仅具有单任务标注。为此，我们考察了两种多任务架构变体，即顺序式变体和共享式变体，然后提出了一种混合变体以及一种重投影损失，以从共享表示中获益，并在使用语义分割进行训练时约束超分辨率图像质量。实验表明，相较于当前最优的顺序式变体，该方法取得了更有利的结果。源代码将发布于 https://github.com/lhoangan/munera。

## Abstract
Super-resolution and semantic segmentation are known to benefit one another, especially in the Earth observation context. However, learning both tasks in a joint model often requires both task annotations, which is impractical and expensive. In this paper, we study the multi-task partially supervised learning paradigm for both tasks, where each example is assumed to have only a single-task annotation. To that end, we examine two multi-task architectural variations, the sequential and shared variants, and then propose a hybrid variant and a re-projection loss to benefit from the shared representation and enforce image quality of super-resolution when training with semantic segmentation. Experiments show favorable results compared to the SOTA sequential variant. Source code will be published at https://github.com/lhoangan/munera.
