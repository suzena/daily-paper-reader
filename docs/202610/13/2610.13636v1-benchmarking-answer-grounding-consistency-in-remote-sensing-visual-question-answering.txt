ABSTRACT 

In grounded remote sensing visual question answering, a model produces a textual answer and identifies relevant ob-jects in the image as grounding evidence. Existing evalu-ations measure answer correctness and localization quality, but do not directly assess answer-grounding consistency. We propose the Answer-Evidence Support Protocol (AESP) to assess this consistency through evidence support: whether the grounding evidence supports the model’s own answer. AESP applies task-specific rules to existence, counting, and comparison questions. We further construct the Grounded Remote Sensing Visual Question Answering (G-RSVQA) benchmark, containing 15,027 samples with questions, ref-erence answers, and all related object-level annotations. Ex-periments on seven grounded vision–language models reveal failures of evidence support across all three question types. Up to 50.82% of correct answers in the evidence evaluation subset are not supported by the provided grounding evidence. 

Index Terms — Remote sensing visual question answer, visual grounding, answer-grounding consistency, benchmark 

1. INTRODUCTION 

Remote sensing imagery provides large-scale observations of the Earth’s surface, but obtaining task-specific information from rapidly growing image collections often requires expert knowledge. Remote sensing visual question answering (RS-VQA) provides a natural-language interface for querying im-age content [1]. Grounded RS-VQA further produces object localizations together with textual answers [2]. These ground-ing regions can serve as visual evidence, allowing users to check an answer against the image. However, accurate lo-calization of relevant objects does not guarantee these objects collectively support the claim stated in the textual answer. 1) We propose AESP with task-specific rules for exis-tence, counting, and comparison questions to assess whether grounding evidence supports the model’s own answer. 

2) We construct G-RSVQA with 15,027 question–answer samples and all related object-level annotations. 

3) We evaluate seven grounded vision–language models, finding that up to 50.82% of correct answers in the evidence evaluation subset lack supporting evidence. 

2. G-RSVQA BENCHMARK 

We construct G-RSVQA to evaluate evidence support for ex-istence, counting, and comparison questions. This evaluation requires verifying which objects the predicted grounding re-gions identify and whether the numbers of grounded instances support the model’s answer. Each question is therefore paired with a reference answer and all related object-level annota-tions, covering every instance of the target classes so that any objects selected by a model as evidence can be verified. As shown in Fig. 2, we collect images and object anno-tations from DIOR [10], NWPU VHR-10 [11], and SODA-A [12] datasets. We parse the annotations to extract object classes and locations, then generate questions and refer-ence answers using rules based on object presence, instance counts, and numerical relations between classes. 3. AESP EVALUATION PROTOCOL 3.1. Answer Extraction and Grounding Verification 

We normalize model responses to Yes/No answers for ex-istence and comparison questions and nonnegative integers for counting questions. Responses already in these formats are parsed directly; otherwise, Qwen3-14B [13] extracts the answer using only the question and original response. Am-biguous or contradictory responses are invalid. After convert-ing predicted regions to original image coordinates, we count covered target instances per class using all related object-level annotations. Each instance is counted once if its ground-truth box center lies within any predicted region.

3.3. Evaluation Metrics 

We measure answer correctness using answer accuracy, with invalid answers counted as incorrect. Localization quality is measured by micro-averaged precision, recall, and F1-score using one-to-one matching between predicted and ground-truth boxes at IoU ≥ 0.5. Answer accuracy is reported on all 15,027 samples. For localization quality and evidence sup-port, we exclude the 5,328 existence questions with No ref-erence answers because their images contain no instances of the target class, leaving 9,699 samples for evaluation. 4. EXPERIMENT 4.1. Experimental Setup 

We evaluate the seven models in Table 1 using publicly re-leased weights, including GeoGround’s task-specific LoRA weights, without additional training on G-RSVQA. Five models generate answers and grounding regions in one response; GeoChat and GeoGround use separate requests whose grounding prompts contain no previously generated answers. We adapt prompts to each model’s interface, coordi-nate format and task. We compare three answer extractors on 400 VLM responses against human reference annotations. As shown in Table 2, Qwen3-14B achieves the highest extraction accuracy of 98.50% and is selected as our answer extractor.

Table 3 reveals a weakness in supporting exact counts. All seven models have lower ES overall on counting than on existence. InternVL3-8B reaches 72.13% on comparison but only 30.20% on counting. Missing some objects may leave the relation between two class counts unchanged. A counting answer loses support whenever the covered count differs from the stated number. Strong comparison support therefore does not establish reliable support for exact counts. Qwen3-VL-8B illustrates why support and correctness must be distinguished: its counting ES overall is 72.37%, while its JS is 50.69%. This gap identifies answers whose grounding matches the stated number even though that number is incorrect. 

5. CONCLUSION 

We proposed AESP to evaluate answer-grounding consis-tency in grounded RS-VQA and constructed the G-RSVQA benchmark with 15,027 samples. Experiments on seven grounded vision–language models show that answer cor-rectness and localization quality do not necessarily imply supporting grounding evidence, with counting showing par-ticularly weak support.
