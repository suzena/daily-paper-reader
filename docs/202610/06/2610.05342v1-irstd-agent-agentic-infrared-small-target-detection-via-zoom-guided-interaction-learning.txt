# ABSTRACT 

Infrared small-target detection plays an important role in maritime monitoring and aerial surveillance. Although multimodal large language models (MLLMs) offer promising capabilities for visual understanding, existing MLLM-based ap-proaches struggle to precisely localize infrared small targets. In this paper, we propose IRSTD-Agent , an agentic framework for infrared small target detection through dynamic visual search. The framework enables an MLLM to adaptively determine where and at what scale to inspect an image and progressively gather fine-grained visual evidence for precise target localization. Five complementary visual tools (PROPOSAL, ZOOM, DETECT, DROP and REFINE) support object candidate discovery, adaptive observation, target localization, hypothesis rejec-tion, and target extent refinement, together enabling a coordinated search process over original-resolution images. To teach the MLLMs to conduct this search, we introduce Zoom-guided Interaction Learning, which uses annotation-derived in-teraction trajectories to supervise tool selection and the corresponding arguments. Through extensive experiments on WideIRSTD-Full and IRSTD-1k datasets, we demonstrate that IRSTD-Agent outperforms the evaluated vision-language mod-els and enhances the precise localization capabilities of MLLMs in IRSTD tasks. 

# 1 INTRODUCTION 

Infrared small target detection (IRSTD) aims to identify and accurately localize dim thermal targets in cluttered backgrounds, supporting applications such as maritime monitoring and aerial surveil-lance. Although specialized deep learning-based approaches have made substantial progress through feature enhancement, context aggregation, and background suppression (Li et al., 2023; Liu et al., 2024a; Yuan et al., 2026), they are typically developed as task-specific models, thereby limiting their generalization capabilities in visual understanding. With the development of multimodal large language models, it has become possible to possess capabilities similar to human visual intelligence and to handle complex visual understanding tasks (Li et al., 2025b; Yuan et al., 2025). Existing efforts to improve the capability of MLLMs in IRSTD task can be broadly grouped into two categories: infrared-domain fine-tuning and cue-guided prompting. As shown in Figure 1(a), the first strategy fine-tunes MLLMs on infrared image–text pairs and task-specific instructions to improve their understanding of infrared imagery, such as Infrared-LLaVA and IRGPT (Jiang et al., 2024; Cao et al., 2025). However, they require substantial annotation effort and incur considerable compu-tational overhead for model finetuning. More importantly, many state-of-the-art MLLMs (OpenAI et al., 2023; Team et al., 2023) are proprietary and cannot provide access to model parameters, mak-ing finetuning inapplicable to some of the strongest existing models and limiting its scalability to rapidly evolving MLLMs. Another strategy introduces auxiliary language cues to guide infrared small target localization, as shown in Figure 1(b). For example, MIRSAM (Zhang et al., 2025b) incorporates textual descriptions of target location and appearance through CLIP-based prompts to support infrared small target segmentation. Similarly, LGNet (Chib & Singh, 2026) leverages MLLMs to generate descriptions of infrared small target locations and incorporates these descrip-tions into a dedicated detection network to improve performance. Although these strategies offer promising directions for adapting MLLMs to IRSTD without parameter updates, the effec-tiveness of precisely localizing infrared small targets remains to be established .1arXiv:2610.05342v1 [cs.CV] 4 Oct 2026 Figure 1: Motivation for IRSTD-Agent. (a) Full-supervision MLLMs adapt to infrared target local-ization through task-specific supervision, incurring annotation and training costs. (b) Prompt-guided MLLMs use auxiliary language cues without updating model parameters, but fail to precisely local-ize small infrared targets. (c) Our IRSTD-Agent employs dynamic visual search to acquire local evidence for target recognition and precise localization. To address these challenges, we propose an IRSTD-Agent , a framework that formulates IRSTD as a dynamic visual search process, as illustrated in Figure 1(c). Instead of relying on a single fixed observation, our approach enables an MLLM to actively acquire local visual evidence and adapt its search through sequential tool interactions. Given an infrared image, the agent identifies candidate regions and adaptively determines where and at what scale to inspect, gathering evidence to localize targets and reject background clutter. To support this process, we introduce five complementary visual tools: PROPOSAL for candidate discovery, ZOOM for adaptive observation, DETECT 

for target localization, DROP for clutter rejection, and REFINE for target extent refinement. By coordinating these tools, our IRSTD-Agent systematically examines object candidate regions and extracts fine-grained visual evidence from original-resolution images, thereby achieving the recog-nition and precise localization of infrared small targets through an adaptive search process. To teach the MLLM to guide this search, we introduce Zoom-guided Interaction Learning ( ZIL ), which uses annotation-derived interaction trajectories to supervise tool selection and the corresponding argu-ments. Through ZIL, the MLLM learns to select informative views, localize targets, and reject distractors based on the acquired visual evidence. Our contributions are summarized as follows: • We introduce IRSTD-Agent, the first agentic framework for infrared small target detection, enabling the model to actively acquire local observations and use visual tools for adaptive visual search and precise target localization in cluttered infrared scenes. • We design five active visual tools (PROPOSAL, ZOOM, DETECT, DROP and REFINE) for IRSTD-Agent to perform dynamic visual search and introduce zoom-guided interaction learning to teach MLLMs to select appropriate search tools and their parameters based on visual evidence, using annotation-derived interaction trajectories as supervision. • Extensive experiments conducted on the WideIRSTD-Full and IRSTD-1K datasets demon-strate that IRSTD-Agent consistently outperforms existing MLLM-based methods and ac-curately localizes infrared small targets across various infrared image scenarios. 

# 2 RELATED WORK 

Infrared Small-Target Detection. Modern IRSTD methods develop specialized architectures and supervision for weak-target representation and localization. DNANet (Li et al., 2023) strength-ens hierarchical feature propagation, MSHNet (Liu et al., 2024a) introduces scale- and location-sensitive supervision, and NS-FPN (Yuan et al., 2026) improves multi-scale feature interaction 2through frequency-guided feature fusion. Other studies explore unified encoder–decoder architec-tures (Wu et al., 2023), target-adapted convolutions (Yang et al., 2025), and learning from sparse point annotations (Yu et al., 2025). AuxDet (Shi et al., 2026) further studies omni-domain IRSTD by incorporating auxiliary acquisition metadata.Recent work has also introduced vision-language priors into IRSTD. SAIST (Zhang et al., 2025a) integrates textual guidance with SAM for infrared small-target segmentation. Overall, these approaches form specialized solutions tailored to infrared small-target detection and are typically deployed through predefined detection pipelines. 

Vision-Language Models for Visual Localization. Recent VLMs have extended multi-modal understanding to spatial localization and detection. General-purpose MLLMs such as Qwen3.5/3.8 (Qwen Team, 2026a;b) and InternVL3.5 (Wang et al., 2025) can follow visual lo-calization instructions and produce coordinate-based predictions. Earlier grounding models explic-itly align natural-language expressions with image regions. MDETR (Kamath et al., 2021) per-forms end-to-end text-conditioned object detection through joint vision-language reasoning, while GLIP (Li et al., 2022) unifies object detection and phrase grounding within a grounded language-image pre-training framework.Models such as LocateAnything (Wang et al., 2026), SenseNova-Vision (Han et al., 2026), Grounding DINO (Liu et al., 2024b), and Florence-2 (Xiao et al., 2024) further develop language-conditioned grounding and structured spatial prediction. 

Visual Chain-of-Thought and Structured Perception Pipelines. Recent work incorporates vi-sual evidence acquisition into multimodal reasoning along two main directions. One line extends chain-of-thought reasoning with intermediate visual interactions, allowing models to identify, re-visit, or zoom into relevant regions during reasoning in a more deliberate and iterative manner. Representative approaches include V*, Visual CoT, DeepEyes, and Pixel Reasoner (Wu & Xie, 2024; Shao et al., 2024; Zheng et al., 2026; Su et al., 2025), which study such capabilities across grounding, fine-grained perception, and multimodal reasoning tasks. Another line organizes vi-sual processing through structured workflows. ZoomEye performs hierarchical image exploration through tree search (Shen et al., 2025), ZoomEarth develops an adaptive cropping framework for high-resolution remote-sensing tasks (Liu et al., 2026), and AgentDet coordinates specialized roles through a shared-blackboard detection pipeline (Li et al., 2026). 

# 3 IRSTD-A GENT 

IRSTD-Agent formulates infrared small-target detection as a dynamic visual search process over the original-resolution image. Rather than predicting all targets from a single resized observation, the agent repeatedly selects visual tools to discover candidate regions, acquire higher-resolution evidence, localize visible targets, and reject unsupported hypotheses. Figure 2 summarizes this process: the current view, candidate list, and interaction history inform each tool call, whose execu-tion updates the state for subsequent decisions. Target localizations are accumulated across search branches, while unsupported candidates are rejected. Implementation Details. IRSTD-Agent is built on Qwen3.5-27B, with separate checkpoints in-dependently fine-tuned on WideIRSTD-Full and IRSTD-1k using the zoom-guided SFT. Training is performed for one epoch with a learning rate of 1 × 10 −5, cosine decay, 5% warmup, BF16 computation, and gradient checkpointing on NVIDIA A100 80GB GPUs. 

Evaluation Metrics. MLLM base models are evaluated using their native boxes without addi-tional refinement or NMS. Grounding methods, Visual Reasoning and Active Search methods, and IRSTD-Agent use center-based refinement and box NMS. We report precision (P), recall (R), and F1-scores for target detection. Following prior IRSTD evaluations (Li et al., 2023; Chen et al., 2022), a prediction is matched to an annotation if their box centers are within 3 pixels in the original image. Matches are established one-to-one using the same criterion for all methods. We additionally report the mean box IoU over matched targets to evaluate localization extent. 4.2 ABLATION STUDIES

4.3 COMPARISON WITH SOTA M ETHODS 

Baseline Setup. Open-Source MLLMs are evaluated by directly prompting them to detect in-frared targets from the full image and return bounding boxes. For models with their own coordinate conventions, the outputs are normalized to a common image-coordinate format before evaluation; for example, Qwen predictions follow its native 0–1000 coordinate protocol and are mapped back to the original image size. VLM-Based Grounding Models support multi-object localization or open-vocabulary detection, so they are directly queried with an infrared-target prompt and evaluated on all returned target boxes in the full image. Visual Reasoning and Active Search Methods are adapted to IRSTD through method-specific search, cropping, or reasoning interfaces. In particular, Zoom-Eye uses Qwen3.5-27B for hierarchical visual search before producing detections. Other methods receive infrared-target queries and structured detection outputs; Appendix A details their training, inference, and output-processing differences. 

WideIRSTD-Full datasets. Direct full-image perception remains challenging on WideIRSTD-Full because tiny targets occupy only a small fraction of large infrared images and their weak re-sponses can be lost during visual compression. As shown in Table 3, Qwen3.5-27B and Qwen3.8-27B achieve 9.15 and 20.02 F1-scores, while LocateAnything-3B reaches 22.31. Grounding models show a similar limitation; Rex-Omni attains 39.06 recall but only 22.74 F1-scores. In contrast, search-based methods benefit from acquiring local evidence. ZoomEye reaches 24.58 F1-scores, RSCoVLM-det reaches 30.17, and IRSTD-Agent achieves 46.87 F1-scores with 71.63 precision. Compared with direct Qwen3.5-27B inference using the same backbone, this is a 37.72 F1-scores gain, supporting the importance of active local observation in wide-area IRSTD.

# 5 CONCLUSION 

In this work, we investigate the challenges of infrared small target detection with multimodal large language models and highlight the importance of actively acquiring fine-grained visual evidence for precise localization. We propose IRSTD-Agent, an agentic framework that formulates detection as a dynamic visual search process. Five complementary visual tools enable candidate discovery, adaptive observation, target localization, hypothesis rejection, and target extent refinement. We further introduce Zoom-guided Interaction Learning, which uses annotation-derived interaction tra-jectories to teach the model to select appropriate tools and their arguments. Extensive experiments on WideIRSTD-Full and IRSTD-1k demonstrate the effectiveness of our framework, demonstrating detection performance superior to other state-of-the-art MLLM-based methods. 

Limitations and Future Work. Sequential tool interactions introduce additional inference over-head, and extremely small or visually ambiguous targets in IRSTD task remain challenging. C.1 IRSTD-A GENT 

The system and observation prompts below use the center-output interface. Line breaks are adjusted for layout. The proposal instruction is appended to the original system prompt in compact form. 

System prompt.                                                                       

> You are an infrared-small-target gaze agent. Inspect only the supplied crop. Coordinates are normalized to the CURRENT crop. Use ZOOM when additional local evidence is needed. Use DETECT when the visible targets can be reliably localized, and DROP when the current hypothesis is unsupported. Emit exactly one JSON action and no prose: ZOOM {type,x,y,size}; DETECT {type,targets:[{x,y}]}; DROP {type}; or PROPOSAL {type}. PROPOSAL runs RF/FFT proposals on the current crop when proposal_allowed=true and additional candidate hypotheses are needed. Proposal points guide search; they are not detections.

Observation prompt. Each user message contains the current crop and the following text. Place-holders are filled with runtime values; history contains parsed actions from the current branch.       

> image_size={image_size}; crop_original={crop_original}; crop_size={crop_size}; step={step}; history={history}. Choose the next action.

Here image_size is [W, H ], crop_original is [u1, v 1, u 2, v 2], crop_size is [u2 −u1, v 2 −

v1], and step is the zero-based branch depth. When an anchor is active, the observation appends:                       

> proposal_anchor_original={anchor}; Follow the current proposal anchor when choosing which local hypothesis to inspect; do not switch to adistant bright target belonging to another proposal.

The anchor uses original-image coordinates. The observation also includes proposal_allowed 

and, after a local P ROPOSAL call, local_proposals_original , a list of original-image can-didate centers. 

Detection action instruction. When D ETECT is selected, IRSTD-Agent localizes all visible tar-gets in the current crop. The detection-specific instruction is summarized below:                                 

> Detect every fully visible infrared small target in this crop. Return all target centers normalized to the CURRENT crop in [0,1], not box corners or original-image coordinates. Output one JSON action: {"type":"DETECT","targets":[{"x":...,"y":...}]} If the crop is background, output {"type":"DROP"}.

IRSTD-Agent predicts the target centers, while P ROPOSAL only supplies candidate locations. The detection instruction belongs to the same policy prompt. The executor maps the predicted centers to the original image before subsequent localization refinement.

Full-image MLLM prompt. The task instruction requests all infrared targets from the full image. A compact rendering is:                                        

> Detect all compact infrared small targets, including dim targets. Exclude broad bright regions, edges, and background texture. Return one tight bounding box per target in the required coordinate format, and an empty list if no target is visible. Output only the requested structured result.

Model-specific output conventions are retained rather than imposing one literal prompt on all mod-els. Grounding prompt. These methods receive an infrared-target text query through their native grounding interfaces rather than the agent’s action prompt. The category query used by YOLO-World and Rex-Omni is:   

> infrared small target
