## 摘要
遥感场景分类是地球观测与地理空间分析中的一项基础任务。现有方法主要遵循三种范式：任务特定的视觉分类、视觉-语言相似度匹配，以及自回归多模态生成。然而，视觉分类器依赖于预定义的标签空间，基于CLIP的方法通过静态图文对齐进行识别，而多模态大语言模型（MLLMs）对于具有明确候选类别的分类任务引入了不必要的词元级生成。为解决这些局限，我们提出RSJEV，一种面向遥感场景分类的单遍多模态决策框架。与传统MLLMs将分类表述为自回归文本生成不同，RSJEV将场景分类重新表述为候选条件化的多模态判别决策过程，其中视觉表示、任务指令和候选类别语义被联合建模。具体而言，我们引入一个OnePass Decider，它提取多模态决策状态，并在候选类别空间内直接估计类别概率，从而在保留视觉-语言交互的同时消除自回归解码。在三个广泛使用的遥感场景分类基准（包括UC Merced、AID和NWPU-RESISC45）上的大量实验表明，与代表性的基于CNN、Transformer、Mamba、CLIP和MLLM的方法相比，RSJEV取得了更优的分类性能。此外，RSJEV仅使用一个紧凑的0.8B参数模型，就显著降低了推理成本，并实现了更好的精度-效率权衡。这些结果证明了状态条件化多模态决策在高效遥感图像理解中的有效性。代码将在 https://github.com/Dongtcs/RSJEV 提供。

## Abstract
Remote sensing scene classification is a fundamental task in Earth observation and geospatial analysis. Existing approaches mainly follow three paradigms: task-specific visual classification, vision-language similarity matching, and autoregressive multimodal generation. However, visual classifiers rely on predefined label spaces, CLIP-based methods perform recognition through static image-text alignment, and multimodal large language models (MLLMs) introduce unnecessary token-level generation for classification tasks with explicit candidate categories. To address these limitations, we propose RSJEV, a one-pass multimodal decision framework for remote sensing scene classification. Unlike conventional MLLMs that formulate classification as autoregressive text generation, RSJEV reformulates scene classification as a candidate-conditioned multimodal discriminative decision process, where visual representations, task instructions, and candidate category semantics are jointly modeled. Specifically, we introduce a OnePass Decider that extracts multimodal decision states and directly estimates category probabilities within the candidate category space, eliminating autoregressive decoding while preserving vision-language interactions. Extensive experiments on three widely used remote sensing scene classification benchmarks, including UC Merced, AID, and NWPU-RESISC45, demonstrate that RSJEV achieves superior classification performance compared with representative CNN-, Transformer-, Mamba-, CLIP-, and MLLM-based methods. Moreover, RSJEV significantly reduces inference costs and achieves a better accuracy-efficiency trade-off with only a compact 0.8B-parameter model. These results demonstrate the effectiveness of state-conditioned multimodal decision making for efficient remote sensing image understanding. The code will be available at https://github.com/Dongtcs/RSJEV.

# RSJEV 论文总结

## 1. 核心问题与研究背景

- **任务定位**：遥感场景分类是地球观测与地理空间分析的基础任务，为环境监测、灾害评估、地理空间情报等应用提供场景级语义信息。其难点在于类内差异大、类间视觉相似（如 desert vs. barren land、railway vs. freeway）、空间分辨率不一。
- **现有三种范式及其局限**：
  - **任务特定视觉分类**（CNN / ViT / Mamba）：依赖任务特定分类头与预定义标签空间，不将自然语言表达的类别语义纳入预测过程，缺少语义先验来消歧，标签空间固定、不可迁移。
  - **视觉-语言相似度匹配**（CLIP 及 prompt-learning 变体）：通过静态图文嵌入相似度打分，视觉特征、任务指令与候选类别之间缺乏直接交互，且性能依赖类别提示词的构造方式。
  - **自回归多模态生成**（MLLM）：把分类当作文本生成，需多步解码输出类别名或解释，推理延迟与算力开销大；而候选类别已显式给定时，真正需要的只是一个离散类别决策。
- **核心动机**：在保留视觉-语言交互的同时，避免迭代式文本生成——将分类重构为**候选条件化的多模态判别决策**问题。

## 2. 方法论

### 2.1 问题形式化
- 样本表示为三元组 $X_i=(I_i, P_i, t_i)$：图像 $I_i$、任务提示 $P_i=[\text{Question},\text{Options}]$、候选类别有序列表 $C=(c_1,\dots,c_K)$ 中的真值索引 $t_i$。
- 模型直接估计候选空间上的概率分布 $p_{i,k}=p_\theta(k\mid I_i,P_i,C)$，并取 $\hat t_i=\arg\max_k p_{i,k}$，$\hat y_i=c_{\hat t_i}$；全程单次前向，不做自回归答案生成。

### 2.2 RSJEV 总体流程
- **多模态骨干**：采用预训练 MLLM（主实验为 Qwen3.5-0.8B），联合处理遥感图像与含分类指令、候选类别描述的提示，输出上下文多模态隐藏状态。
- **OnePass Decider（OPD）**：核心新增模块，负责判别式决策。

### 2.3 关键技术细节（算法流程）
1. 骨干最终层隐藏状态 $H_i=[h_{i,1},\dots,h_{i,N_i}]^\top\in\mathbb{R}^{N_i\times d}$。
2. 在指定答案槽 `[RSSC]` 处抽取决策表示：$h_i^{ans}=H_i[s_i,:]^\top\in\mathbb{R}^{d\times1}$。该表示已条件化于图像、任务指令与候选类别描述。
3. 每个候选项对应一个 token id $u_k$，从预训练语言建模头 $W_{LM}\in\mathbb{R}^{L\times d}$ 中按行抽取，构成候选权重矩阵 $W_C$，计算得分 $z_i=W_C h_i^{ans}$。
4. 仅在候选集合内做 softmax 归一化：$p_{i,k}=\exp(z_{i,k})/\sum_j \exp(z_{i,j})$，取最大概率项作为预测。
5. **与原始 JEV 的区别**：JEV 需按选项数把同一问题展开成多条输入路径分别前馈，重复计算图像特征与文本提示；RSJEV 只需**一条输入路径、一次前向**即完成决策。

### 2.4 训练设置
- AdamW，学习率 $1\times10^{-4}$，weight decay 0.01，50 步 warm-up；
- 损失 = 交叉熵 + Brier 分数正则；标签平滑 0.05；10 个 epoch；
- 训练时随机水平翻转；最大 token 长度 1536；FP32 精度。

## 7. 优点

- **问题重构精准且有针对性**：

- **问题重构精准且有针对性**：准确指出现有三类范式各自的"错配"——生成式 MLLM 用多步解码解决一个本质上是单步离散选择的问题，对比式 VLM 缺少指令与候选的显式交互，任务特定分类器缺少语义先验。将分类重写为"候选条件化的判别决策"在概念上简洁自洽，且与候选集合已给定的实际使用场景高度吻合。
- **复用 LM head 的设计巧妙**：不新建分类头，而是按候选 token id 从预训练语言建模头中按行抽取权重构成 $W_C$，使候选词的语义嵌入在决策中直接生效，既保留了预训练的语言-语义对齐，又几乎不增加参数（零新增参数），这是"零成本注入语义先验"的优雅做法。
- **单路径前向的效率红利真实且可验证**：相对 JEV 需按选项数展开多路径、重复前馈图像与提示，RSJEV 一条路径一次前向即得全候选分布，效率提升是结构性的而非工程调优的产物，1.68 GB / 102 ms / 9.79 FPS 的结果与之自洽。
- **效率对比维度完整**：同时报告显存、单图延迟、吞吐，并给出与 Qwen3.5 的 4.31× 与 InternVL3 的 2.39× 倍数关系，比只报 FLOPs 或只报精度更具工程参考价值。
- **跨骨干验证意识**：在 Qwen3.5-0.8B 与 InternVL3.5-1B 两个不同家族的骨干上验证 OPD，说明模块设计不依赖特定 MLLM 的 tokenizer 或输出头结构。
- **精度增益的稳健性**：在三个数据集、四个指标上一致最优，而非只在单一指标或单一数据集上领先；跨骨干实验中 Precision 提升幅度最大（+9.84 点），说明 OPD 主要修复的是生成式解码在"选对类别"上的系统性弱点。
- **方法描述的可复现性较好**：超参（AdamW、lr $1\times10^{-4}$、weight decay 0.01、50 步 warm-up、10 epoch、标签平滑 0.05、最大长度 1536、FP32）、硬件、batch size 均给出，算法流程给出 5 步伪代码级描述。

- 效率实验扩展到多 batch（如 1/4/16/32）与多分辨率，报告 3–5 次重复的均值±标准差。
- 对 MLLM 基线进行超参搜索后再比较，或至少在附录公开其微调配置与训练曲线，以排除"基线欠训练"的质疑。
- 引入等参数或等训练预算的对照（如对 0.8B 骨干做更大规模持续预训练），或在结论中明确声明比较的边界。
- 增加混淆矩阵、t-SNE 可视化与错误案例分析，检验判别式决策是否确实缓解了类间相似导致的混淆。
- 探索开放集与拒识扩展：候选集合外加一个"以上都不是"的 token，检验 OPD 在分布外样本上的行为。

## 10. 一句话总结

RSJEV 把遥感场景分类从"自回归生成类别名"重构为"在给定候选集合上做一次候选条件化的多模态判别决策"，通过复用预训练 LM head 的候选词权重并在 `[RSSC]` 槽位上单次前向打分，用 0.8B 骨干在 UCM/AID/NWPU 上取得 97.72/96.30/94.58 的 F1 与 1.68 GB、102 ms/图的效率优势，范式方向清晰且工程价值突出，但消融缺位、与 JEV 无定量对照、基线公平性与候选鲁棒性未充分验证，是其当前最主要的可信度短板。
